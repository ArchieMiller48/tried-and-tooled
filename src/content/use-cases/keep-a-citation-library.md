## Who this is for

Students and researchers who need a bibliography they can reuse, not a one-off summary of a paper.

## How to choose

- **You need the citation in the document:** Zotero, with the word-processor plugin described in the [documentation](https://www.zotero.org/support/).
- **You are building a local reference list:** on 17 Nov 2026, Zotero 10.0.8 on Linux looked up three identifiers in about 16 to 18 seconds each. The metadata was correct for all three, apart from a lower-case press in The MIT press. An APA 7 bibliography exported as HTML. Storage, sync, the browser connector, PDF attachment and the word-processor plugin were not part of that check.
- **You are only storing references, not a pile of PDFs:** the free 300 MB row on the [storage page](https://www.zotero.org/storage).
- **You still have to find the papers:** [Research and summarise sources](../../use-cases/research-and-summarise-sources/) is the search. This page is the library afterwards.
- **The essay still has to be edited:** [Proofread and edit a piece of writing](../../use-cases/proofread-and-edit/).

The note below is a local check of Zotero 10.0.8 on Linux only, dated 17 Nov 2026. No Zotero account, no sync, no browser connector, no Word or LibreOffice plugin and nothing paid. Zotero storage was not part of it. The standard task on this page has not been run. Storage prices were read on 16 Nov 2026.

## Hands-on test (17 Nov 2026)

This note is for Zotero on a computer, the top pick. The version was Zotero 10.0.8, the Linux x86_64 build from zotero.org. The check ran on 17 Nov 2026. No Zotero account was used. The profile was a fresh local profile. There was no sync, no browser connector, no Word or LibreOffice plugin and nothing paid. Zotero storage, the budget pick, was not part of it.

The download was 118.3 MB, as a .tar.xz file. On first launch Zotero opened its install-confirmation page in the browser and started a LibreOffice citation-plugin installer. The installer was cancelled. Zotero's own window was usable about 63 seconds after launch, including dealing with those two windows. The welcome panel suggested the Quick Start Guide, the Zotero Connector and syncing. No account or payment prompt blocked use.

The task was a student building a reference list. Add three sources by identifier, add one web page by hand, put two items in a collection, and export an APA 7 bibliography.

DOI 10.1038/nature14539 took about 18 seconds. The item was a journal article, Deep learning, by LeCun, Bengio and Hinton, dated 2015-05-28, in Nature, volume 521, pages 436–444. The metadata was correct.

ISBN 9780262035613 took about 16 seconds. One earlier attempt did not register because focus moved away. The item was a book, Deep learning, by Goodfellow, Bengio and Courville, 2016. The publisher was The MIT press, with a lower-case press as returned. It was correct apart from that casing.

DOI 10.1145/3442188.3445922 took about 18 seconds. The item was a conference paper, On the Dangers of Stochastic Parrots..., by Bender, Gebru, McMillan-Major and Shmitchell, 2021, in the ACM FAccT proceedings, published by ACM, pages 610–623. The metadata was correct.

A web page was added by hand: the Food Standards Agency allergen labelling page. The title, website title, URL and accessed date were all saved.

Create Bibliography from Items used the style APA Style 7th edition and saved as HTML. The file had four entries, alphabetised. The DOIs were links. The Nature article included issue number 7553. The undated web page used (n.d.). The MIT press casing carried through.

A collection named Bakery dissertation was created. Dragging items onto it did not add them in this test session. Right-click Add to Collection worked, and both items showed.

Settings showed Log In / Create Account. The profile was not signed in.

No account was needed for a working local library. Identifier lookups took about 16 to 18 seconds each, with correct metadata for 3 of 3 sources, apart from the publisher casing on the book. The APA 7 bibliography came out in one export. First launch opened the browser page and a word-processor plugin installer. Dragging items onto the collection did not add them in this session. The menu worked. Storage, sync, the browser connector, PDF attachment and citing from Word or LibreOffice were not tested.

The standard task on this page has not been run. That task is the same five public web pages saved, one citation inserted into a document, a check of whether the fields match the page, and a record of what storage tier the files would need.
