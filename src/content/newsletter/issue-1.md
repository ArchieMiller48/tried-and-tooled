<h2>Featured stack: vibe-code an MVP</h2>

<p><strong>The job:</strong> go from an idea to a live web app with login and a database, mostly by prompting, without getting stuck in a tool you can't leave.</p>

<div class="callout">
<ol>
<li><p><strong>Prototype:</strong> Lovable, or Bolt.new on a budget. Prompt the pages, auth and data model.</p></li>
<li><p><strong>Own the code:</strong> GitHub sync from day one, so you can leave the builder whenever you like.</p></li>
<li><p><strong>Refine:</strong> an AI editor such as Cursor, for the precise edits chat builders struggle with.</p></li>
<li><p><strong>Review before shipping:</strong> CodeRabbit or Greptile, to catch security and logic slips in AI-written code.</p></li>
</ol>
</div>

<ul>
<li><p><strong>Top pick: Lovable.</strong> Free gives you 5 build credits/day (max 30/month). Pro is $25/mo (100 credits) or $21/mo billed annually. <a href="https://docs.lovable.dev/introduction/subscription-plans" target="_blank" rel="noopener noreferrer">Source</a></p></li>
<li><p><strong>Budget pick: Bolt.new.</strong> Free gives you 300K tokens/day and 1M/month, with Bolt branding. Pro is $25/mo. <a href="https://bolt.new/pricing" target="_blank" rel="noopener noreferrer">Source</a></p></li>
<li><p><strong>Watch out:</strong> on Lovable's Free plan you can't edit or download code or use a custom domain. Fine for testing an idea, not for launching. <a href="https://docs.lovable.dev/introduction/subscription-plans" target="_blank" rel="noopener noreferrer">Source</a></p></li>
</ul>

<p><em>Status: pending hands-on test.</em> Our planned test is to build a to-do app with email login, per-user data and a public URL on Lovable, Bolt.new and Replit. We'll record time to first deploy, credits used and fix-up prompts, and whether the exported code runs locally.</p>

<h2>One practical tip</h2>

<p><strong>Connect GitHub before you write your second prompt.</strong> Builders like Lovable offer Git sync, and once your project lives in a repo you can switch tools, roll back a bad prompt and add an automated reviewer. If the repo is public, CodeRabbit is free (<a href="https://www.coderabbit.ai/pricing" target="_blank" rel="noopener noreferrer">source</a>). Greptile's Starter plan is free for one developer with 50 credits a month (<a href="https://www.greptile.com/pricing" target="_blank" rel="noopener noreferrer">source</a>).</p>
